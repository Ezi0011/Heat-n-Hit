HEAT-N-HIT

L'Arène de Combat Tactique en Temps Réel

🔥 Bienvenue dans l'Arène

Heat-n-Hit est un jeu de combat multijoueur frénétique qui revisite l'esprit des classiques comme Bomberman, mais avec une dimension stratégique accrue. Ici, ce n'est pas seulement une question de chance : votre survie dépend de votre capacité d'anticipation, de votre précision de tir et de votre gestion de l'espace.

Votre objectif est simple : rester le dernier en vie en éliminant vos adversaires à coup de boules de feu.

📱 Comment Rejoindre la Partie

Le jeu utilise un système unique où votre smartphone devient votre manette de jeu physique.

  1. Scannez pour Jouer : Approchez-vous de l'écran principal et scannez le QR Code affiché avec l'appareil photo de votre téléphone.
  2. Interface de Contrôle : Une fois connecté, votre écran de téléphone se transformera automatiquement en interface de commande.
  3. Entrez dans la Bataille : Préparez-vous au compte à rebours !

🎮 Maîtriser le Gameplay

Pour devenir le champion de l'arène, vous devez comprendre les mécaniques de base :

Déplacements Fluides

Utilisez le joystick virtuel sur votre mobile pour naviguer. Esquiver les tirs adverses est aussi important que d'attaquer.

Boules de Feu

Appuyez sur l'écran pour lancer un projectile. Attention : les boules de feu mettent du temps à voyager, vous devez donc viser là où l'ennemi sera.

L'environnement : Utilisez les murs indestructibles pour vous protéger, et détruisez les blocs destructibles pour vous frayer un chemin ou piéger un adversaire dans un cul-de-sac.

🏆 À quoi s'attendre ?

Une partie de Heat-n-Hit est divisé en plusieurs manches :

  • Les joueurs sont divisé en 4 groupes équilibrés
  • Le top 25% des survivants de chaque groupe sont qualifié pour la finale
  • Le dernier survivant de la finale remporte le tournoi !
