HEAT-N-HIT

L'arene de combat tactique en temps reel

Bienvenue dans l'arene

Heat-n-Hit est un jeu de combat multijoueur frenetique inspire des classiques comme Bomberman, avec une dimension tactique plus forte.

Votre objectif est simple : rester le dernier en vie en eliminant vos adversaires avec vos boules de feu.

Comment rejoindre la partie

Votre smartphone devient votre manette de jeu.

  1. Scannez pour jouer : approchez-vous de l'ecran principal et scannez le QR Code avec votre telephone.
  2. Controle mobile : une fois connecte, votre telephone affiche les boutons de commande.
  3. Entrez dans la bataille : attendez le lancement du tournoi et le compte a rebours.

Maitriser le gameplay

Pour gagner, vous devez anticiper les mouvements adverses et gerer l'espace autour de vous.

Deplacements

Utilisez la croix directionnelle de votre mobile pour vous deplacer case par case sur la map.

Boules de feu

Appuyez sur le bouton de tir pour lancer un projectile dans votre direction actuelle.

Environnement : utilisez les murs solides pour vous proteger et detruisez les blocs cassables pour ouvrir le terrain.

Deroulement du tournoi

Une partie de Heat-n-Hit est divisee en plusieurs manches :

  • Les joueurs sont repartis en 4 groupes equilibres.
  • Les 25% meilleurs survivants de chaque groupe sont qualifies pour la finale.
  • Le dernier survivant de la finale remporte le tournoi.
